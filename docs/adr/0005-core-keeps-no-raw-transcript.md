# Core 不归档原始会话，记忆条目自带证据

宿主自己的会话日志就是一份可回放的完整记录，Core 再存一份原文属于重复归档。我们决定 Core **不保存原始会话文本**：Perception 从宿主日志读取原料，产出 Memory Item 之后原料即可遗落；若原料在产出前就丢失，视为「没记住」，接受这个损失。

这不是疏忽而是取舍：原始语料只是原料，产物才是资产。

## Consequences

- **记忆条目必须内嵌证据摘录**，不能只存指向原文的指针——指针会悬空，悬空的溯源等于没有溯源。
- **Plan 不单独存储。** 宿主会话日志已完整记录整段可回放历史（`Session.deriveMessages()` 从事件日志派生），Core 再存一份计划是重复归档；若宿主会话被删，就让计划随之消失，不补救。
- **无法因抽取质量提升而重跑旧原料**。改进抽取器只影响之后的会话，不回溯历史。
- **评估只能用当时的条目**，不能事后从原文重建黄金集。这条在写 Evaluation 的验收用例时必须记住。
- Core 不是会话的系统记录者；会话的唯一记录者是宿主（见 ADR-0001）。
