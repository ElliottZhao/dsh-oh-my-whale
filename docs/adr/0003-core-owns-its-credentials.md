# Core 自持配置与凭据

Core 需要 LLM 凭据来做抽取与整理。Core 维护自己的配置文件与密钥，不读取宿主的配置或凭据。

Core 不是宿主的一部分。跨进程去读另一个程序的配置，会让凭据在两个系统之间隐式共享：轮换只有一处会做，泄露面却有两处，而且宿主的配置形状不属于 Core 可以依赖的契约。代价是用户必须为 Core 单独配置一次 provider；这个代价换来的是两个系统之间一条清晰、可审计的边界。

## Consequences

Core 读不到凭据时降级为「只记不抽」（纯本地规则入库），并在 Ledger 记一次降级事件，而不是静默失败。降级用配置快照的 `degradedProviders` 显式报告：凭据此刻取不到的 provider 不阻止 Core 启动，仍留在出站白名单里；用到它时才降级并记 Ledger。
