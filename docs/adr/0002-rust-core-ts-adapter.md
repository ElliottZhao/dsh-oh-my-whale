# Core 用 Rust，编排留在宿主侧

Core 承担存储、检索、时序与图索引；编排、提示词装配与宿主接缝留在 TypeScript。领域 schema 以 Rust 为单一事实源，适配层消费生成的类型。

备选「全 Rust 服务端」会让同一套领域模型在两个运行时里各写一遍，schema 漂移是必然结果；备选「全 TS 单进程」放弃 Core 的独立生命周期与跨宿主复用，也就放弃了把 Core 做成可被多个 Host 共用的内核这一目标。Rust 在这里买的是自包含单二进制与长期常驻，不是尚未测量的性能。

## Consequences

适配层的类型不手写，由 Core 的 schema 生成；任何领域字段变更都要走 Core 侧改动并经代码生成传导到 TS——这是有意的摩擦，用来阻止两侧各改各的。
