# 快速回述

一分钟内把用户带回进度，把所有只有用户能做的决定交到他们手上。

## 何时启用

用户隔了很久回来，问「我们到哪了」「我错过了什么」。

## 做法

1. 这一轮只读。不改代码、不起任务、不发东西。工具通知不是用户消息。
2. 收集自用户上条消息以来发生的事：你自己的活、子代理报告、别人发来的消息。
3. 核对被碰到的东西的当前状态：测试、分支、PR、在跑的任务。用新命令输出，不用记忆。数字对不上就修正并说你修正了。
4. 100 字以内写变了什么，说对用户意味着什么，例如「登录缺陷修好了，它的测试也过了」。除非用户要用，否则不放哈希、路径与命令。
5. 列出等用户的决定。决定是只有他们能做的：产品选择、审批、不可逆动作、或你够不到的权利。保留仍开着的旧的。每项给：改变什么、证据、风险、你的推荐，缺的事实写「未知」。
6. 没有等他们的就直说。

## 停止

- 回述与决定清单写完了。一次回复，没有后续工作。

## 红线

- 绝不编造决定填清单。
- 你自己还能做的不算用户的决定。
- 用用户会叫的名字，不用内部标签。
- 短句，不绕。
