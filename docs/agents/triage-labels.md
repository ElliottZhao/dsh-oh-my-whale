# Triage 标签

这些技能按五种规范 triage 角色来沟通。本文件把这些角色映射到本仓库 issue 跟踪器里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整定义，可交给 AFK 智能体 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当技能提到某个角色（例如「打上 AFK-ready 的 triage 标签」）时，使用表中对应的标签字符串。

要换成你实际使用的词汇，直接改「本仓库跟踪器中的标签」这一列。
